# 出張ルート表 自動化ツール

院名または地名を入力するだけで、

- 住所・営業時間・法人名（②店舗マスタ 135院分から自動）
- 車移動時間（前の訪問地からの、OpenStreetMapによる概算）

が自動で入る、出張ルート表の作成ツールです。日程は何日分でも追加でき、
完成したルート表はExcelファイルとして書き出せます（保存・共有はファイル単位）。

## できること／できないこと

- ✅ 院名を入れると住所・営業時間・法人名が自動で入る（②店舗マスタ135院分を内蔵）
- ✅ 前の訪問地からの車移動時間を自動計算（OpenStreetMap / OSRM、APIキー不要・無料）
- ✅ 日程・訪問先の追加/削除/並べ替え
- ✅ Excelファイルとして出力（配布・印刷用）
- ✅ JSONファイルとして保存 → あとで読み込んで編集を再開できる
- ⚠️ 車移動時間はGoogleマップではなく無料のOpenStreetMapベースです。Googleマップと数分程度ずれることがあります
- ⚠️ 住所は「〇丁目」レベルで地図検索します（番地までの正確な地点ではなく、その街区の代表地点からの計算になります）
- ⚠️ 保存はファイル単位です（クラウド上にデータが残るわけではありません。人に渡すときはJSONファイルを送ってください）

## 1. まず手元のパソコンで試す

1. このフォルダごと保存する
2. `起動.bat` をダブルクリック
3. 黒い画面が起動したら、ブラウザで `http://127.0.0.1:8766` を開く
4. 停止するときは、黒い画面で `Ctrl + C`

この方法は自分のパソコンだけで完結します。他の人と共有したい場合は、下記の手順で無料のサーバーに公開してください。

## 2. みんなが使えるようにする（無料ホスティングに公開）

一度公開すれば、URLを知っている人は誰でも（Claudeの無料版だけ持っている人でも）ブラウザで開いて使えます。
**Gitの知識は不要です。**GitHubのサイト上でファイルをドラッグ＆ドロップするだけです。

### 手順A：GitHubにコードを置く

1. https://github.com/ にアクセスし、アカウントがなければ「Sign up」で無料登録
2. ログイン後、右上の「＋」→「New repository」
3. Repository name に `shukko-route-tool` などと入力し、「Public」のまま「Create repository」
4. 作成後の画面で「uploading an existing file」というリンクをクリック
5. このフォルダの中身（`app.py`、`requirements.txt`、`render.yaml`、`data`フォルダ、`static`フォルダ、`templates`フォルダ）を**フォルダごと**ドラッグ＆ドロップ
   - `起動.bat` はアップロード不要です（ローカル専用のファイルです）
6. 下部の「Commit changes」をクリック

### 手順B：Renderに公開する

1. https://render.com/ にアクセスし、「Get Started」→ GitHubアカウントでサインアップ
2. ダッシュボードで「New +」→「Web Service」
3. さきほど作った `shukko-route-tool` リポジトリを選択して「Connect」
4. 設定画面で以下を確認・入力（`render.yaml` があるので多くは自動入力されます）
   - **Name**: 好きな名前（これがURLの一部になります）
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: Free
5. 「Create Web Service」をクリックすると自動でビルド・起動が始まります（数分かかります）
6. 完了すると画面上部に `https://（好きな名前）.onrender.com` のようなURLが表示されます。これを共有してください。

### 無料プランの注意点

- 15分間アクセスが無いと自動的にスリープします。次にアクセスした人は、起き上がるまで最初の1回だけ数十秒待つことがあります。
- 頻繁に使う場合は、Renderの有料プラン（月額1000円前後〜）にするとスリープしなくなります。

### 更新したいとき

コードを直したくなったら、GitHubのリポジトリ画面でファイルを開いて編集（鉛筆アイコン）→ Commit すれば、
Renderが自動で再デプロイします。

## 3. データの仕組み（②店舗マスタの更新方法）

`data/hospitals.json` に135院分のデータが入っています。新しい院を追加したり、
営業時間が変わったときは、このファイルを直接編集するか、Claudeに「hospitals.jsonのこの院の営業時間を〇〇に変えて」と
頼んでください。編集後はGitHubにアップロードし直せば、Render側にも反映されます。

### 院を追加・住所変更したときは座標も更新する

住所から緯度経度を調べるサービス（OpenStreetMap）はアクセス制限が厳しいため、
院・本社・主要駅の座標は `data/geocode.json` に事前に保存してあります。
院を追加したり住所を変えたときは、手元のパソコンで次を実行して更新してください。

```
python tools/build_geocache.py
```

実行すると `data/geocode.json` が更新されるので、GitHubにアップロードし直せば反映されます。
（更新しなくても動きますが、その院だけ毎回問い合わせが発生し、遅くなります）

## 4. よく使うルート（プリセット）の編集

`static/presets.js` に地域ごとのルートが入っています。院名は `data/hospitals.json` の
正式名称と**完全一致**させてください。一致していれば住所・営業時間・法人名が自動で入ります。

- 関東圏のルート … 本社を起点・終点に自動で追加します
- 地方のルート … `start` に書いた主要駅を起点に自動で追加します
- 起点は9:00出発、院の滞在は15分で自動的に入ります（どちらも画面上で変更可能）

## 4. 使い方のコツ

- 院名は入力すると候補が出ます（②店舗マスタに登録されている院名）。候補にない場所（ホテル・駅・空港・訪問先の個人名など）は自由に入力してください。
- 住所欄は自動入力されますが、手で書き換えることもできます（ジオコーディングの精度が悪いときの微調整用）。
- 車移動時間がうまく出ないときは、住所欄をもう少し具体的な地名（例：「〇〇市〇〇町」など）に書き換えて、行の🔄ボタンで再計算してください。
- 「全再計算」ボタンは、JSON読み込み後や住所を一括で見直したときに使います。
